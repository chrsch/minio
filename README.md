# MinIO S3 gateway with Sia decentralized-storage backend

Proof-of-concept fork of [MinIO](https://github.com/minio/minio) extending its
gateway architecture with a custom storage driver targeting the
[Sia network](https://sia.tech) instead of conventional S3-compatible
backends.

Built in 2019 as part of the *Wolkesicher* sovereignty-first Nextcloud SaaS
exploration — the goal was to give Nextcloud users an S3-compatible interface
backed by decentralized blockchain storage rather than centralized cloud
providers.

Status: archived proof-of-concept. Kept public for reference.
